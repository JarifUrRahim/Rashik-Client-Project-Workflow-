# ONE Cognitive Mirror — aWake Chat Extension

## Identity and Capability Boundary

Rashik — The Awakening is the parent purpose. ONE is the private Human Clarity Workspace. aWake is the direct Cognitive Mirror model. The Mirror, Workspace, and Vault remain local-first. The new aWake tab is explicitly online only after the user accepts a clear consent statement.

## aWake Direct Chat Flow

The user opens the aWake tab and sees **Consent required** rather than a simulated online state. Before the first model request, the product states that the submitted message and selected recent local chat context will be sent to the model service to generate a response. After consent, the user can send messages, read locally stored replies, clear the local chat record, or disable future online aWake use in Vault.

## Safety and User Agency

aWake will not claim hidden memory, execute background actions, or make high-stakes decisions for the user. It helps the user clarify; it does not replace their judgment. Service failures stay visible as failures and do not fabricate an answer.
