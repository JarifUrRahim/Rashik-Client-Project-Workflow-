## Approved Future Milestones

The next candidate milestones are a global aWake pause switch, Conversation-to-Workspace capture, user-approved long-term memory, document-to-understanding, Bangla voice interaction, and an authenticated aWake gateway for product-to-product reuse.

## Deliberate Non-Claims

The current personal Cloud Computer does not host the strong language model behind aWake chat. The current release does not claim automatic memory, autonomous external action, voice interaction, document intelligence, or full self-hosted inference.
