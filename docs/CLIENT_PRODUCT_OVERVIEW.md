# ONE and aWake — Client Product Overview

## Executive Summary

ONE is a mobile Human Clarity Workspace built in the Rashik — The Awakening product lineage. Its core contribution is not simply a chat interface. It gives a person a calm, deliberate place to capture a thought, make sense of it, identify one humane next step, and keep only the records they choose. The optional aWake conversation is designed as a Cognitive Mirror: it supports clearer thinking without pretending to replace the user’s judgment.

The first delivery combines local-first reflection tools with a consent-based online chat experience. A user can save reflections to their own Workspace, inspect the current data boundary in Vault, select বাংলা or English, remove local chat history, turn off future online aWake use, or reset the entire device workspace.

## What the User Can Do

| User need | ONE behavior |
|---|---|
| Capture a difficult thought | The Mirror accepts a thought and offers Clarify, Plan, and Reflect structures. |
| Turn reflection into an action | The user can save an entry to Workspace and retain a visible next step. |
| Speak with aWake | The aWake tab requests explicit consent before sending a message to the online model route. |
| Control privacy | Vault makes local storage, chat history, consent state, deletion, and reset visible. |
| Work in Bangla or English | The language switch persists on-device and guides both interface copy and aWake reply language. |

## Product Differentiation

Generic AI chat systems focus on answering a prompt. ONE adds a deliberate personal-workspace layer around that answer. It separates local reflection from online inference, provides user-visible memory controls, and makes a saved thought or plan part of a reviewable workspace rather than a disappearing conversation.

> **aWake is designed to clarify the user’s thinking, not to claim authority over it.**

## Current Scope

The current release includes the mobile experience, local device persistence, bilingual UI, direct consent-based chat, a server-side chat route, safety-oriented system instruction, responsive mobile keyboard behavior, and Workspace save flows. Voice interaction, document understanding, formal long-term memory, multi-product integrations, and a self-hosted language-model runtime remain future milestones.
